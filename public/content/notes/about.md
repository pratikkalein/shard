# About this note

This is a regular Obsidian markdown note, embedded into the canvas through a
**file node**.

- Standard markdown works: **bold**, *italic*, `inline code`
- So do lists, links, and tables

| Node type | Rendered as            |
| --------- | ---------------------- |
| text      | markdown               |
| file      | embedded note or image |
| link      | live web embed         |
| group     | labelled background    |

> Edit the canvas in Obsidian, copy it (and this note) into `public/content/`,
> then push.
